# Mounting hard drive

I scrapped my first laptop for parts and ripped out the old HDD. After wiping it, I followed these steps.

1. Mount it

```bash
sudo mkdir -p /mnt/data
sudo mount /dev/sda1 /mnt/data
sudo chown $USER:$USER /mnt/data
```

2. Make it persistent

```bash
sudo blkid /dev/sda1
```

Copied the UUID= value, then add here:

```bash
echo 'UUID=57bd4aac-e478-45e8-ae43-924500ee0a7d /mnt/data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab
sudo umount /mnt/data && sudo mount -a && df -h /mnt/data
```
